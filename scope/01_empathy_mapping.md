
# Empathy Mapping
**Input to Empathy Mapping** | Answers from user interview

## Objective
The primary objective of Empathy Mapping is to understand the user's perspective by capturing what they think, feel, say, and do in a specific situation.

## Helps to Identify
| Element    | What to capture                                 |
| ---------- | ----------------------------------------------- |
| **Needs**  | What the user needs to succeed                  |
| **Thinks** | What the user may be thinking or worrying about |
| **Says**   | What the user explicitly communicates           |
| **Does**   | What the user actually does                     |
| **Focus**  | What is the user focusing on?                   |
| **Pains**  | Frustrations, fears, obstacles                  |
| **Feels**  | Emotions experienced during the situation       |
| **Gains**  | Desired outcomes, expectations, motivations     |

## Output: User Thinks, Says, Feels, Does insights
| Empathy Map | Your Statement | Evidence from User Feedback | Validation |
| ----------- | -------------- | --------------------------- | ---------- |
| **THINKS**  |                |                             |            |
| **SAYS**    |                |                             |            |
| **FEELS**   |                |                             |            |
| **DOES**    |                |                             |            |

## Validation Rules
| Validation                  | Definition                                                                                         |
| --------------------------- | -------------------------------------------------------------------------------------------------- |
| 🟢 **Strongly Supported**    | Multiple direct pieces of user evidence clearly support the statement.                             |
| 🟢 **Supported**             | At least one clear piece of evidence directly supports the statement.                              |
| 🟡 **Partially Supported**   | The evidence relates to the statement, but the statement is stronger or broader than the evidence. |
| 🔴 **Not Supported**         | The available feedback does not support the statement.                                             |
| ⚪ **Insufficient Evidence** | There is not enough information to make a reliable determination.                                  |
