
## Opportunity Analysis Input
| Opportunity Analysis | Input to Opportunity Analysis |
|--|--|
| Opportunity Analysis | Output of Root Cause Analysis |

## Objective
The primary objective of Opportunity Analysis is to convert problems, unmet needs, and root causes into concrete improvement opportunities — identifying where meaningful value could be created.

## Helps to Identify
| Element | What you learn |
|--|--|
| Opportunity | What could be improved |
| Linked Problem/Root Cause | Which pain point or root cause this opportunity addresses |
| Expected Value | What improves if this opportunity is acted on |
| Priority | How important this opportunity is (Low/Med/High) |
