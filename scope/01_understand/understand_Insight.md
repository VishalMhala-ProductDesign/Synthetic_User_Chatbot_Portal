
## Understand Insight Input
| Understand Insight | Input to Understand Insight |
|--|--|
| Understand Insight | Output of Empathy Mapping, JTBD Analysis, and User Journey Mapping |

## Objective
The primary objective of Understand Insight is to move each of Empathy Mapping, JTBD Analysis, and User Journey Mapping from Evidence to Interpretation to Insight to Design Implication - then synthesize all three into a single phase-level insight and a working design hypothesis going into Analyze.

## Helps to Identify
| Element | What you learn |
|--|--|
| Empathy Mapping — Evidence | What users said/felt/did that's most relevant |
| Empathy Mapping — Insight | What that evidence means |
| Empathy Mapping — Design Implication | What the design should do about it |
| JTBD Analysis — Evidence | What the effort/behavior evidence shows |
| JTBD Analysis — JTBD | The job statement in "When... I want... so I can..." form |
| JTBD Analysis — Design Implication | What the design should do about it |
| User Journey Mapping — Evidence | What a specific journey stage shows |
| User Journey Mapping — Insight | What that stage's evidence means |
| User Journey Mapping — Design Implication | What the design should do about it |
| Pattern | The theme that repeats across all three |
| Phase Insight | The single synthesized insight the whole Understand phase reveals, going into Analyze |
| Working Design Hypothesis | A preliminary, testable design idea this phase's insight points toward - provisional, to be refined or discarded as later phases add evidence |

## Output
Each block below follows: Evidence (Users say/do) → Insight (Users need) → Design implication (Make). Keep each field to one concise sentence in that exact form - not a paragraph. Each source produces AS MANY of these Evidence → Insight → Design implication sets as the evidence genuinely supports - one for every distinct piece of evidence that reveals its own insight, not just one. Generate the maximum the source actually supports; do not artificially cap it at one, and do not pad with repetition or near-duplicates just to add more.
