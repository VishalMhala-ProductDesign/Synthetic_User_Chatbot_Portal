## Objective
The primary objective of AI Capability Analysis is to define what AI must actually be capable of doing to perform the AI-owned steps identified in the Human–AI Workflow.

## Helps to Identify
| Element | What you learn |
|--|--|
| Capability | What the AI needs to be able to do |
| Description | What this capability means in practice |
| Linked AI Step | Which step in the Human–AI Workflow this capability supports |
| Priority | How critical this capability is (Low/Med/High) |
