## Objective
The primary objective of Trust & Control Analysis is to ensure the user can understand why AI did something, verify it, and stay in control — defining how the user can trust and control AI appropriately at each interaction point.

## Helps to Identify
| Element | What you learn |
|--|--|
| Interaction Point | Which AI-involved interaction this trust/control question applies to |
| Transparency Shown | Why AI flagged/acted, what data it used, how confident it is |
| User Controls Available | Whether the user can review the evidence, reject the recommendation, or undo the action |
| Handback Trigger | When AI must hand control back to the human |
