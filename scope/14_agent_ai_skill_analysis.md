## Objective
The primary objective of Agent / AI Skill Analysis is to translate each AI capability into the specific skills, actions, and tools the agent actually needs in order to perform it.

## Helps to Identify
| Element | What you learn |
|--|--|
| Skill/Action | The specific action the agent must be able to perform |
| Description | What this skill actually involves |
| Tool(s) Needed | What API, system, or data source the skill depends on |
| Linked Capability | Which capability (from AI Capability Analysis) this skill supports |
