## Objective
The primary objective of Analyze Insight is to synthesize what Task Flow Analysis, Workflow Analysis, Decision Analysis, Pain Point + Friction Analysis, and System Mapping reveal together as a single insight - not a summary of each finding, but what the work, decisions, and friction combined mean going into Diagnose.

| Element | What you learn |

| What Task Flow Analysis Reveals | The core task-flow insight |
| What Workflow Analysis Reveals | The core workflow insight |
| What Decision Analysis Reveals | The core decision-point insight |
| What Pain Point + Friction Analysis Reveals | The core friction insight |
| What System Mapping Reveals | The core system-context insight |
| Pattern | The theme that repeats across all five |
| Phase Insight | The single synthesized insight the whole Analyze phase reveals, going into Diagnose |
| Working Design Hypothesis | A preliminary, testable design idea this phase's insight points toward - provisional, to be refined or discarded as later phases add evidence |
