## Objective
The primary objective of Pain Point + Friction Analysis is to identify where the experience breaks down — the specific problems, obstacles, effort, delays, and frustrations the user runs into, and how much impact each one actually has.

## Helps to Identify
| Element | What you learn |
|--|--|
| Problem | What is going wrong for the user |
| Friction | Where the experience becomes difficult, slow, or confusing |
| Impact | How severe the problem is (Low/Med/High) |
| Frequency | How often the problem occurs (Rare/Occasional/Frequent) |
| Context | When/where the problem happens |
