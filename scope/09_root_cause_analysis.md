
## Root Cause Analysis Input
| Root Cause Analysis | Input to Root Cause Analysis |
|--|--|
| Root Cause Analysis | Output of System Mapping |

## Objective
The primary objective of Root Cause Analysis is to understand why the problem is actually happening — laddering down from the visible pain point through contributing causes until the underlying root cause is reached.

## Helps to Identify
| Element | What you learn |
|--|--|
| Cause Category | The kind of cause behind the problem (People, Process, Tools/Systems, Environment - only the ones that apply) |
| Specific Causes Found | What specifically within that category is contributing |
| Why (laddering) | Each successive "why" that leads deeper toward the root cause |
| Impact On The Problem | How much this cause actually contributes to the problem |

## Output

|--|--|--|
| People | AI identifing specific causes found | AI identifing impact on the problem |
