## Objective
The primary objective of JTBD (Jobs to Be Done) Analysis is to understand the fundamental things the user is trying to accomplish.

## Helps to Identify
| Focus | What you discover |
|---|---|
| Pattern | What is the pattern |
| Job | What the user is trying to accomplish |
| Motivation | Why they need to accomplish it |
| Desired Outcome | What successful completion looks like |
| Context | When/where the job happens |
| Constraints | What makes the job difficult |
| Emotional needs | How the user wants to feel |
| Functional needs | What they need to accomplish practically |
