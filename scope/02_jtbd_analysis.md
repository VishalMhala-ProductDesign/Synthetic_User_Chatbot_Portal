
## JTBD Analysis
**Input to JTBD Analysis** | User Thinks, Says, Feels, Does insights from empathy mapping

## Objective
The primary objective of JTBD (Jobs to Be Done) Analysis is to **understand the fundamental job the user is trying to accomplish, independent of the product or solution they currently use.**

## Helps to Identify
| Focus | What you discover |
|---|---|
| **Pattern** | What is the pattern based on Empathy Evidence |
| **Job** | What the user is trying to accomplish |
| **Motivation** | Why they need to accomplish it |
| **Desired Outcome** | What successful completion looks like |
| **Context** | When/where the job happens |
| **Constraints** | What makes the job difficult |
| **Emotional needs** | How the user wants to feel |
| **Functional needs** | What they need to accomplish practically |

## Output: Jobs + Goals
| Empathy Evidence | Pattern | Need / Motivation | Job | Goal / Outcome |
|---|---|---|---|---|
| | | | | |

## Example
| Empathy Evidence | Pattern | Need / Motivation | Job | Goal / Outcome |
|---|---|---|---|---|
| Concerned about data quality + frustrated by tedious data work + says data quality is a pain + uses specialized tools | Data preparation requires significant effort | Confidence in data reliability | Prepare and validate reliable simulation data | Trust simulation results |
| Uncertain about simulation/model validation + complexity + computationally intensive + uses tools | Validation is complex and resource-intensive | Confidence in model/results | Validate model/results efficiently | Obtain trustworthy simulation results |
| Stakeholder communication is important + confidence in communication + engages stakeholders early | Stakeholder alignment requires continuous coordination | Alignment and shared understanding | Communicate findings and coordinate stakeholders | Achieve stakeholder alignment |
| Regulatory requirements are important + concerned about permitting + works with regulatory experts | Regulatory compliance requires specialized knowledge | Confidence in compliance | Navigate regulatory requirements | Avoid compliance/permitting issues |
| Wants automation + frustrated by tedious work + uses specialized tools | Repetitive work consumes valuable time | Reduce manual effort | Automate repetitive activities | Improve efficiency |
| Prioritizes tasks and manages time effectively + feels satisfaction from prioritization | Workload requires active prioritization to stay on top of multiple responsibilities | Confidence in managing workload | Prioritize and manage workload effectively | Meet deadlines without feeling overwhelmed |
| Continuous learning is necessary + stays up-to-date with industry developments | Field evolves quickly, requiring ongoing skill development | Confidence and competence in a changing field | Stay current with industry developments and best practices | Maintain up-to-date expertise |
